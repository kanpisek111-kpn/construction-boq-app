## ✨ ฟีเจอร์หลัก (Features)

### 1. ระบบจัดการหลายโครงการ (Project Dashboard)
* **พอร์ตโฟลิโอรวม**: สรุปจำนวนโครงการทั้งหมด, มูลค่างานรวมทั้งพอร์ต (Grand Total), พื้นที่ก่อสร้างรวม (ตร.ม.) และสถานะโครงการหน้างานจริง
* **ค้นหา & คัดกรอง**: ค้นหาโครงการตามชื่อ, ชื่อลูกค้า, เบอร์โทรศัพท์ หรือสถานที่ก่อสร้าง พร้อมฟิลเตอร์คัดกรองตามสถานะ (`ร่างแบบ`, `เสนอราคา`, `กำลังก่อสร้าง`)
* **สร้างโครงการใหม่**: กำหนดชื่อโครงการ, ขนาดพื้นที่ใช้สอยบ้าน (ตร.ม.), ข้อมูลลูกค้า และสร้างรายการ BOQ พื้นฐานให้ทันที
* **สำรอง & กู้คืน**: ดาวน์โหลดไฟล์สำรองโครงการ (`.boq.json`), คัดลอกทำสำเนา (`Duplicate`), และนำเข้าไฟล์โครงการเดิมกลับมาทำงานต่อได้ตลอดเวลา

### 2. ตารางถอดแบบ BOQ ละเอียด 10 หมวดงานก่อสร้าง
คำนวณแยกค่าวัสดุ (Material), ค่าแรง (Labor) และการเผื่อเศษวัสดุ (Waste %) ตามมาตรฐานงานช่างไทย:
1. **งานเตรียมพื้นที่ & ฐานราก/เสาเข็ม**
2. **งานโครงสร้าง คสล.** (ฐานราก, เสา, คาน, พื้นสำเร็จรูป, พื้นหล่อในที่)
3. **งานโครงหลังคา & มุงกระเบื้อง/เมทัลชีท**
4. **งานผนังก่ออิฐ** (อิฐมวลเบา, อิฐมอญ, อิฐบล็อก) & ฉาบปูน & เสาเอ็น-ทับหลัง
5. **งานประตูห้อง & ประตู-หน้าต่างอลูมิเนียม**
6. **งานฝ้าเพดาน & ปูพื้นกระเบื้อง & สีอาคาร/สีกันสนิมเหล็ก**
7. **งานตกแต่งภายใน-ภายนอก** (บัวพื้น, บัวปูน, หินกาบ, ผนังกรุ)
8. **งานสุขาภิบาล ท่อประปา & สุขภัณฑ์ห้องน้ำ**
9. **งานระบบไฟฟ้า แสงสว่าง & ตู้ควบคุม & คำนวณสายไฟ วสท.**
10. **งานภายนอก** (รั้วรอบบ้าน, ประตูรั้ว, โรงจอดรถ, รางระบายน้ำ, ปั๊มน้ำ-ถังเก็บน้ำ)

### 3. เครื่องมือคำนวณวิศวกรรมเฉพาะทาง (Smart Engineering Estimators)
* **โครงสร้าง คสล.**: ปริมาตรคอนกรีต (ลบ.ม.), ไม้แบบ (ตร.ม.), เหล็กเสริม DB12, DB16, เหล็กปลอก RB6/RB9, ลวดผูกเหล็ก, แผ่นพื้นสำเร็จรูป
* **บันได คสล.**: คำนวณขั้นบันได ลูกตั้ง-ลูกนอน ชานพัก คอนกรีต ไม้แบบ ราวบันได และจมูกบันได
* **โครงหลังคา & กระเบื้อง**: หลังคาปั้นหยา/จั่ว/เพิงหมาแหงน คำนวณเหล็กกล่อง C-Channel, อะเส, จันทัน, แป, ฉนวนกันความร้อน และครอบสันหลังคา
* **ผนัง & ก่อฉาบ**: จำนวนก้อนอิฐ, ปูนก่อ, ปูนฉาบ, น้ำยากันซึม, ทับหลังรอบช่องเปิด
* **สายไฟ วสท.**: ตลับจุดสวิตช์-เต้ารับ, ขนาดสาย THW/VAF/NYY/VCT ตามขนาดโหลดเบรกเกอร์
* **ท่อประปา & สุขาภิบาล**: ท่อ PPR / PVC ท่อน้ำดี น้ำเสีย ท่อน้ำทิ้ง ถังบำบัดน้ำเสีย ถังดักไขมัน และถังเก็บน้ำ

### 4. สั่งซื้อวัสดุหน้างาน (Site Procurement View)
* รวบรวมสรุปยอดรวมวัสดุทั้งหมดที่ต้องใช้จริงในไซต์งาน เช่น ปูนซีเมนต์ (ถุง), ทรายหยาบ/ทรายละเอียด (ลบ.ม.), หิน 1-2 (ลบ.ม.), เหล็กเส้น (เส้น/กก.), อิฐมวลเบา (ก้อน)
* มีระบบติ๊กเช็ครายการสั่งซื้อและติดตามสถานะจัดส่งเข้าหน้างาน

### 5. แผนงานการก่อสร้าง & งวดงาน (Gantt Chart & Milestones)
* กำหนดสัดส่วนเปอร์เซ็นต์งวดงาน (3 / 4 / 5 / 6 งวด)
* สร้างแผนผัง Gantt Chart แสดงระยะเวลาและกำหนดการส่งมอบงานแต่ละงวดอัตโนมัติ

### 6. ใบเสนอราคาทางการ & พิมพ์ PDF (Quotation Document)
* ออกใบเสนอราคา (Quotation) รูปแบบมาตรฐานวิชาชีพ
* แสดงข้อมูลบริษัทผู้รับเหมา, ข้อมูลลูกค้า, งวดการชำระเงิน, เงื่อนไขการรับประกัน และลงนามสัญญา
* รองรับการพิมพ์และส่งออกเป็นเอกสาร PDF คมชัด

## 🚀 วิธีติดตั้งและรันโปรเจกต์ (Getting Started)

### ความต้องการของระบบ (Prerequisites)
* Node.js เวอร์ชัน 18 ขึ้นไป
* npm หรือ pnpm

### การติดตั้ง (Installation)

```bash
# Clone โปรเจกต์ลงเครื่อง
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME

# ติดตั้ง Dependencies
npm install
```

### การเริ่มรันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server)

```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่:
* **Local**: `http://localhost:3000/`
* **Network (มือถือ/แท็บเล็ตในวง Wi-Fi เดียวกัน)**: `http://<IP_ADDRESS>:3000/`

### การ Build สำหรับ Production

```bash
npm run build
```

ไฟล์ build จะถูกสร้างไว้ที่โฟลเดอร์ `dist/` สามารถนำไป Deploy บน Vercel, Netlify หรือ GitHub Pages ได้ทันที

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Build Tool**: [Vite 5](https://vitejs.dev/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Icons & Fonts**: Google Material Symbols & Google Fonts (Plus Jakarta Sans, Sarabun)
* **Storage**: LocalStorage + SessionStorage (ทำงานแบบ Offline-first ข้อมูลไม่หายเมื่อรีเฟรช)
